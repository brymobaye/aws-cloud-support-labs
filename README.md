# AWS Cloud Support Labs

Hands-on AWS, Linux, networking, CI/CD, and cloud troubleshooting labs demonstrating practical skills for Cloud Support and Cloud Engineer roles.

## About This Repository

This repository documents practical cloud engineering exercises, troubleshooting scenarios, and hands-on AWS labs.

Each practical follows an evidence-based approach:

**Problem → Investigation → Commands and Tools → Root Cause → Resolution → Validation → Lessons Learned**

The goal is to demonstrate how I investigate infrastructure issues, troubleshoot cloud services, and document technical findings.
